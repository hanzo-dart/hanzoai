# Changelog

## 0.1.0

- Initial release. Typed Dart client for the Hanzo Cloud `/v1/` platform API.
- First-class services: `agents`, `sessions`, `machines`.
- Hanzo IAM-native Bearer auth (`MemoryAuthStore` / `AsyncAuthStore`).
- Raw `HanzoCloud.send()` escape hatch for the full `/v1/cloud/*` surface.
